# 自研引擎 vs 聚宽 — 对比说明

## 时序差异

| 环节 | 自研引擎 (quantify) | 聚宽 (JoinQuant) |
|------|---------------------|-------------------|
| 策略运行时间 | 每日开盘 | `run_daily(..., time='open')` |
| 信号数据 | 今日开盘 + 上一交易日及以前的历史数据，默认预加载回测开始日前 365 天 | 今日开盘 + 上一交易日及以前的历史数据 |
| 订单成交 | 当天开盘价加价格滑点 | 当天开盘价加价格滑点 |
| 报表估值 | 日终收盘价估值 | 日终估值 |
| 基准收益 | 复权收盘价，前一交易日为起点 | 平台基准口径 |
| 交易单位 | 一手 `100` 份取整 | 聚宽按交易单位自动取整 |
| ETF 分红 | 登记日锁定持仓，派息日现金入账 | 平台自动处理 |

当前 `joinquant_strategy.py` 已按自研引擎的开盘撮合模型写法对齐。

## 手续费

| 参数 | 自研引擎 | 聚宽对齐设置 |
|------|---------|-------------|
| 费率 | 0.0005 (万五) | `open_commission=0.0005, close_commission=0.0005` |
| 最低 | 0.5 元 | `min_commission=0.5` |
| 类型 | ETF | `type='fund'` |

## 滑点

两引擎均设为 `0.002` 比例滑点。聚宽的 `PriceRelatedSlippage(0.002)` 会把成交价按半个点差调整：买入价约为 `open * 1.001`，卖出价约为 `open * 0.999`；ETF 成交价按 `0.001` tick 四舍五入。

| 参数 | 自研引擎 | 聚宽对齐设置 |
|------|---------|-------------|
| 滑点 | `slippage_rate=0.002` | `PriceRelatedSlippage(0.002)` |

## ETF 分红

自研引擎会读取 `etf_dividend`：在登记日按收盘后持仓数量记录权益，在派息日把 `持仓数量 × div_cash` 加入现金。以 README 默认策略的 `2019-01-01 → 2019-06-30` 回测为例，`510300.SH` 在 `2019-01-21` 派息，每份 `0.059` 元，首笔持仓 `30100` 份会增加现金 `1775.90` 元，后续买入数量因此与聚宽交易详情对齐。

## 年化口径

聚宽默认 250 个交易日；自研引擎 Web 报表已按 250 计算（`compute_metrics` 仍用 252，
终端日志与 Web 指标会有小幅偏差）。

## 指标口径

- 策略净值按收盘价估值，因此收益、年化收益、最大回撤与聚宽的日终指标面板对齐。
- 日胜率按“策略日收益 > 基准日收益”统计，而不是单纯统计策略正收益天数。
- 盈亏比按聚宽交易详情的平仓盈亏口径统计：成交价差加持仓期分红，不扣手续费。
- 信息比率按 `(策略年化收益 - 基准年化收益) / 跟踪误差` 计算。

## 运行步骤

1. 打开 https://www.joinquant.com → 新建策略
2. 粘贴 `joinquant_strategy.py` 全部代码
3. 回测区间：2022-01-01 → 2025-12-31
4. 初始资金：100000
5. 点击"运行回测"
6. 对比聚宽页面指标面板与自研引擎 Web 回测工作台

## 仍可能存在的差异

- 聚宽平台基准和风险指标可能使用内部行情修正与精度规则，小数位可能有轻微差异。
- 聚宽的停牌、涨跌停、成交失败、基金交易单位等边界规则可能比当前自研引擎更完整。
